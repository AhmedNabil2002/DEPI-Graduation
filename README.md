# PhysioHome

Professional physical therapy at home: a React app built as the graduation project of the DEPI (Digital Egypt Pioneers Initiative) Front-End track.

## Tech Stack

- React 18 + Vite
- Redux Toolkit
- React Router
- React Icons

## Project Structure

```
src/
  components/   reusable UI components
  pages/        application pages
  layouts/      shared layouts
  router/       routes
  store/        Redux store
  context/      React context
  hooks/        custom hooks
  data/         static data
```

## Getting Started

```bash
npm install
npm run dev
```

Build for production with `npm run build`.
